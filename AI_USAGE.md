# AI_USAGE.md

## AI Tool(s) Used

- ChatGPT (Microsoft Copilot / GPT-based assistant)

---

## Prompts Used

1. Help me understand the Django project structure for a box recommendation system.

2. Explain Django models, serializers, views, URLs, and testing with examples.

3. Help me design Product, Box, and Order models.

4. Help me implement a recommendation algorithm that selects the most suitable shipping box.

5. Suggest unit tests for the recommendation system.

6. Help me write README documentation for the project.

---

## Accepted Output

- Project architecture suggestions.
- Explanation of Django concepts.
- Initial model design ideas.
- Unit testing suggestions.
- API structure recommendations.
- Documentation guidelines.

---

## Modified Output

- Adjusted model fields according to assignment requirements.
- Refined recommendation logic to fit project needs.
- Modified API responses and endpoint structures.
- Reorganized application architecture into Products, Boxes, Orders, and Recommendations apps.

---

## Rejected Output

- Some generated examples did not completely match the assignment requirements.
- Some code examples lacked project-specific validation.
- Generic implementations were adjusted to fit the project's business logic.

---

## Mistakes Found in AI Suggestions

- Some examples assumed simplified packing rules.
- Some initial recommendations did not consider all assignment constraints.
- Certain code snippets required adaptation to fit the actual application structure.

---

## Verification Process

The final implementation was verified through:

1. Manual code review.
2. Django migrations validation.
3. API endpoint testing.
4. Unit test execution.
5. Admin panel verification.
6. Functional testing using sample products and boxes.

All final code was reviewed and modified before inclusion in the project.
